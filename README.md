# 代码结构

- configs
    - json存放在这里无法读取，暂时移动在resource中
- controllers
    - 游戏控制器：控制整个游戏界面的逻辑初始化，事件监听和分发
    - 主牌区控制器：接收游戏控制器的调用，主牌区的逻辑实现
    - 堆区控制器：接受游戏控制器的调用，堆牌区逻辑实现
    - 回退控制器：接受游戏控制器的调用，回退操作的实现
- managers
    目前为空
- models
    - 卡牌模型：cpp文件没有逻辑，头文件定义了一些属性的接口和初始化
    - 游戏模型：控制整个游戏界面的数据层面的变动，数据变动结束后调用视图层函数更新视图和动画移动
    - 回退模型：定义了回退时需要的主要属性和简单的实现了一些栈的操作，来实现回退功能
- services
    目前为空，应该将游戏视图中的动画函数封装到此文件夹下
- utils
    - json解析类，用于读取卡牌数据
    - 关卡配置文件读取
- views
    - 卡牌：读取卡牌配置json，获取到花色数字等信息，读取静态资源并创建Sprite添加到卡牌视图的Sprite上。
    - 游戏：设置了游戏界面的视图信息，读取卡牌配置json获取卡牌位置信息，并设置主牌区和堆牌区和回退按钮。
# 一些内容的增加
    - 增加卡牌只需要在卡牌配置文件中增加
    - 添加新的回退类型需要在回退模型的枚举中添加。
